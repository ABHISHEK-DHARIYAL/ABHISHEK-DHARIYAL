# Setup (5 minutes)

1. Repo name must be exactly: ABHISHEK-DHARIYAL/ABHISHEK-DHARIYAL (public).
2. Upload everything in this zip to the repo root, keeping the folders:
   - README.md
   - .github/workflows/snake.yml
3. Repo > Settings > Actions > General > Workflow permissions:
   set to "Read and write permissions".
4. Repo > Actions tab: enable workflows if asked, then run
   "Generate Snake" with "Run workflow".
5. Wait ~1-2 minutes and refresh your profile.

Check: a branch named "output" should appear in the repo after the run.
